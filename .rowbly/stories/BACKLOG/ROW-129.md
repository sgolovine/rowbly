## Problem
- `src/tui/screens/threads/factory-view/use-factory-view.ts:62`, `thread-pane/use-thread-pane.ts:56` and `stories/threads-tab/use-threads-tab.ts:151` set `now` every second, which re-renders whole panes and their unmemoized rows.
- `src/tui/hooks/use-thread-changes.ts:6` re-reads the factory status every 5 s. `use-async.ts` always sets a new data object, so the shell re-renders even when nothing changed.

## Fix
- Run the clocks only while a running Thread is shown, and stop them when the pane is hidden or the full-screen view covers it.
- Give `useAsync` an optional equality check, or compare the factory status (for example by JSON text or a version field) before `setState`, so an unchanged read does not render.
- Update `use-async.test.ts` and the hook tests.

## Done when
An idle board with the factory stopped produces no React commits between user actions. A 5 s poll that reads the same status causes no render.
