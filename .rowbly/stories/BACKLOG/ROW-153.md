Tab and EditorModeTab have the same props, ref, `useMouse` handling and ` label ` text. Only the selected colors are different: Tab uses `accent` / `onAccent`, EditorModeTab uses `selection`.

Files:
- `src/tui/components/tab/tab.tsx`
- `src/tui/components/editor-mode-tab/editor-mode-tab.tsx`

Add a `variant?: "accent" | "subtle"` prop to `Tab`, use it in the full screen editor, and delete `EditorModeTab`.
