StoryFinder copies most of SearchableSelectPicker.

Files:
- `src/tui/shell/story-finder/story-finder.tsx`
- `src/tui/components/searchable-select-picker/searchable-select-picker.tsx`

Both keep query and cursor state, run `fuzzySearch` in a `useMemo`, clamp the selection, compute the same window of rows, reset the cursor when the query changes, and handle esc / up / down / enter with `useKeyCapture`. Both render a `TextInput`, an empty text, a slice of `SelectListRow` and a counter.

Differences: StoryFinder has a search prefix, wheel scroll and a count line. The picker has ctrl+l (clear the query) and the `Selected:` line.

Make a generic `FuzzyPicker<T>` in `src/tui/components/` with slots for `prefix`, `header` and `emptyText`. SearchableSelectPicker becomes a thin wrapper, and StoryFinder becomes `Modal` + `FuzzyPicker`. Expected saving: about 70 lines.
