The two sections are almost the same file. Only the names, the service calls, the row component and the confirm message are different.

Files:
- `src/tui/screens/settings/tags-section/tags-section.tsx`
- `src/tui/screens/settings/custom-fields-section/custom-fields-section.tsx`

Both have the same list/new/edit/remove mode, hints, keys (`n`, `enter`/`e`, `d`), loading guard, empty text, "+ New" button, form modal and destructive confirm dialog.

Make one `CrudListSection<T>` (or a `useCrudList<T>` hook) with props such as `noun`, `load`, `remove(item)`, `itemKey(item)`, `renderRow`, `renderForm` and `confirmMessage(item)`. Use it in both sections. Expected saving: about 140 lines.
