## Goal

`CloseButton` and `ExpandButton` are the same component. Each has a `useRef<DOMElement>`, a call to `useMouse(ref, { onClick }, useIsActive())` and a `Box flexShrink={0}` with one `Text` in `theme.inkFaint`. Only the glyph is different: `✕` for `CloseButton`, and `⤢` (expand) or `⤡` (collapse) for `ExpandButton`.

Merge them into one component, `BorderIcon({ glyph, onClick })`, so that each clickable icon in a border uses the same code. The user sees no change.

## Scope

In scope:

- A new component folder `src/tui/components/border-icon/` with `border-icon.tsx` and `index.ts`. It exports `BorderIcon`.
- Replace all uses of `CloseButton` and `ExpandButton` with `BorderIcon`.
- Delete `src/tui/components/close-button/` and `src/tui/components/expand-button/`, and remove their lines from `src/tui/components/index.ts`.
- Update the documentation that names the old components.

Not in scope:

- `FullScreenButton` (`src/tui/components/full-screen-button/`). It has a different look (accent colour, bold, a key hint) and a `clickable` flag.
- Changes to the glyphs, colours, padding or behaviour of the icons.
- New keys or new icons.
