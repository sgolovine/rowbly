## Problem
`src/tui/screens/stories/story-dependency-view.ts:41` calls `dependencyCandidates`, which runs `dependencyError` with a fresh graph and a cycle search for each candidate Story (O(n³)). `edit-story-form.tsx:161` and `new-story-form.tsx:127` call it inside render. The profile showed 170 ms for each open of the edit form.

## Fix
- Build the graph one time in `dependencyCandidates` (use the index from the Story about linear row building) and test each candidate against it.
- Compute the choices in a `useMemo` keyed on `[stories, story.id, dependsOn]` in both forms.
- Update `story-dependency.test.ts`.

## Done when
Opening the edit form of a Story on a 125-Story board spends under 10 ms in dependency code.
