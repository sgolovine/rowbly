## Goal

The user can see the worker hosts and change the placement policy in the TUI Settings.

Read the Spec `remote-worker-hosts`, sections "Setup of a worker host" and "Placement". Read the `rowbly-tui-design` skill.

## Scope

In scope:

- A Hosts section in Settings. It lists the hosts with the SSH target, the worker limit, the result of the last check and whether the host is on for the current Project.
- Actions: turn a host on or off for the Project, change the worker limit, and run a check.
- A control for the `placement` setting, with `prefer-local` as the default.

Not in scope:

- `host add` and `host login` in the TUI. They stay in the CLI, because the login needs a terminal.

## Acceptance criteria

- The TUI calls the same services as the CLI. No domain logic goes in a component.
- Check the screens in a real terminal with the `rowbly-screenshots` skill.
