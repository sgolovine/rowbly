## Problem
The TUI has no use of `React.memo`. Every shell state change re-renders Header, Sidebar, StoryPanel, StorySidebar, ShellOverlays and Footer. New objects on each render defeat any memo:
- `src/tui/hooks/use-async.ts:114` spreads a new object each render, and `shell.tsx:54` uses it as the `FactoryStatusContext` value.
- `src/tui/shell/shell/use-shell-data.ts:167` spreads a new board each render (`withActivity`).
- `src/tui/shell/shell/shell-props.ts:148-216` builds fresh prop objects and inline closures for each child.
- `shell.tsx:64` passes an inline object to `LayoutContext`.

## Fix
- `useMemo` the context values and the board (keep the same reference when the inputs are the same).
- Make the prop builders and the row callbacks stable (`useCallback`, or handlers that read from a ref).
- Wrap Header, Sidebar, StoryPanel, StorySidebar and Footer in `memo`.
- Follow the React handler patterns of the `rowbly-code-style` skill.

## Done when
An arrow key on the board re-renders the story list and the footer hints only. Check with the React profiler or with a render counter in a temporary debug build.
