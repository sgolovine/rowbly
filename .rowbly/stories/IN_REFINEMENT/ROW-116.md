## Goal

ROW-96 gives the manager a remote executor, but only tests give the manager its worker hosts and the transport of each host. This Story gives the factory daemon the real values, so that a user can use a worker host in production.

- The `workerHosts` dependency of the factory manager reads the host registry (`listHosts` in `src/services/host/host.ts`) and the hosts that are on for the Project (`hostProjectFor` in `src/services/host-project/host-project.ts`). A host that is not `enabled` is not in the list.
- The state and the providers of each host come from the short check of the main machine (`quickHostCheck` in `src/services/host-check/host-check.ts`). A host that is not ready is not `connected`. When ROW-97 adds the heartbeat, the heartbeat gives the state.
- The daemon makes the SSH transport of each host (`createSshTransport`) and makes sure that the host has the exact Rowbly version (`ensureHostVersion`) before the first launch.
- The daemon gives the remote executor of ROW-96 the path of `rowbly` on the host (`remoteRowblyPath`) and the clone of the Project on the host.

Read the Spec `remote-worker-hosts`, sections "Setup of a worker host", "Version" and "Placement".

Not in scope: the heartbeat, the reconnect and the host states of ROW-97.
