## Goal

End-to-end tests of the remote factory, from the launch to the board.

Read the Spec `remote-worker-hosts`.

## Scope

In scope:

- Daemon tests with the faux provider and the fake transport, with a main machine and one or two worker hosts.
- A full run on a host: launch, outbox, Stage move, completion and canonical commit.
- A disconnect during a run, then a reconnect. Each change arrives one time.
- A cancel while offline: the stop goes first, the entries are held, then apply and discard.
- An inbound update while a remote worker runs.
- Placement with each policy and with a full host.
- Attachments in both directions.

Not in scope:

- Tests with real SSH or live credentials.

## Acceptance criteria

- The tests run in `pnpm test` without a network.
