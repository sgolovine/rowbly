## Problem
`src/services/story-watch/story-watch.ts:62` and `src/services/thread/thread-watch.ts:43` open `fs.watch` with `recursive: true` on the whole project dir. `.rowbly/runtime` has 537 folders and 122 MB of session data, so each watcher adds an inotify watch per folder, and every write in `runtime/` wakes all watchers before the filter drops it. Each hook instance (shell, thread pane, threads tab, factory view) adds another watcher.

## Fix
- Watch `stories/` (recursive, for the Stage folders), `attachments/` and the specific files (`state.json`, the thread metadata folder) instead of the project root.
- Share one watcher per project root between the hooks, with a subscriber list.
- Keep the quiet time and the ignore rules. Keep `persistent: false`.
- Update `story-watch.test.ts` and `thread-watch.test.ts`.

## Done when
The TUI opens at most one recursive watcher per project root, and a write in `.rowbly/runtime/` calls no Story callback.
