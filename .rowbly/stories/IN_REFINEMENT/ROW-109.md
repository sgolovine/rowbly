Split from ROW-108. The goal of this part: attach a file that the user copied to the clipboard.

When a user copies a file in a file manager (for example Nautilus, Finder or Explorer), the paste key in the TUI (`ctrl+v`, or `alt+v` on Windows) and `rowbly add-attachment <story> --from-clipboard` must attach that file to the Story. Today only a PNG image on the clipboard is accepted (`src/services/clipboard/clipboard.ts`).

This part needs ROW-108 first, because ROW-108 lets a Story keep a file of any type.

Facts from refinement of ROW-108:

- The native binding `@mariozechner/clipboard` 0.3.9 has `availableFormats()`, `getText()`, `getImageBase64()`, but no reader for a list of copied files.
- On Wayland, a copied file is `text/uri-list` in `wl-paste --list-types`. On X11, `xclip -selection clipboard -t TARGETS` shows the types. macOS and Windows need their own commands (for example `osascript` and PowerShell `Get-Clipboard -Format FileDropList`).
- Other image types on the clipboard (for example `image/jpeg` from `wl-paste`) are also part of this work.
