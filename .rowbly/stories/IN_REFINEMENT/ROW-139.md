## Goal

Make the start of the TUI faster. The profile of ROW-137 found a hot spot in the import of the TUI modules at launch.

## Hot spot

- Function: `loadInProductionMode` (`src/services/react-mode/react-mode.ts`), called from `src/cli-main.ts` for `import("./tui/index.js")`.
- Inclusive CPU time: 138 ms on the main thread (median run). The top-level evaluation of `cli-main` is 232 ms inclusive and holds this time.
- Most of the time is module compile and load (`compileSourceTextModule`, `ModuleWrap`, `realpathSync`) for the TUI bundle (about 540 KB), Ink, React and Yoga.
- Scenario: the production-mode 12 s board session of ROW-137 (`docs/architecture/tui.md`, `## Performance`). 138 Stories, 140x38, Node 24, `NODE_ENV` not set.

## Ideas

- Enable the Node module compile cache (`module.enableCompileCache()`) for the TUI path.
- Load the screens that the board does not show (Settings, Factory view, onboarding) with a dynamic import.

## Notes

The measured launch time to the first Story row is 1.28 s. Measure again with the method of `## Performance` after the change.
