The settings rows all use the same column layout: `SelectionRow` > `Box` > some `<Box width={w} flexShrink={0}>` cells > a last `<Text wrap="truncate-end">` cell. Four of them use the same selected color rule (`selected ? inkMuted : inkFaint`).

Files:
- `src/tui/screens/settings/custom-field-row/custom-field-row.tsx`
- `src/tui/screens/settings/tag-row/tag-row.tsx`
- `src/tui/screens/settings/prompt-row/prompt-row.tsx`
- `src/tui/screens/settings/stage-row/stage-row.tsx`
- the rows in the loops of `src/tui/screens/settings/check-list/check-list.tsx` and `src/tui/screens/settings/stage-model-list/stage-model-list.tsx`

Make `ColumnRow({ selected, active, onClick, columns })` in `src/tui/components/`, where each column has an optional `width` and a `content` (a node, or a function of `selected`). Optionally add a `ColumnList<T>` that also computes the column widths. Expected saving: about 120 lines. This also makes the CRUD list section story smaller.
