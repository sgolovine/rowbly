The two fields share the code that opens the picker.

Files:
- `src/tui/components/searchable-select/searchable-select.tsx`
- `src/tui/components/searchable-multi-select/searchable-multi-select.tsx`

Duplicated:
- `isQueryText` is word for word the same.
- `PICKER_HINTS` differs only in "choose" and "add".
- `openPicker` (Modal + SearchableSelectPicker), the `useMainOverlay` / `useId` / `useEffect(open/close)` setup and `useKeyCapture(focused && !picker)`.
- The key handler: the ctrl/meta early return, enter opens the picker with an empty query, typed text opens it with that text.

Make a `usePickerField({ field, options, value, title, verb, hideSelected, onPick })` hook that returns `{ picker, open(query), inline, keyHandler(input, key) }`. The multi select keeps only its left / right and backspace handling. Expected saving: about 50 lines.
