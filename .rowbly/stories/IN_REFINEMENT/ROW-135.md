## Problem
`src/tui/mouse.ts:8` turns on `?1003h`, so the terminal reports every pointer move. `src/tui/hooks/mouse.ts:186-197` runs `hit()` twice per move (`dragOver` and `hover`), and `hitArea` at `:117-130` calls `measureElement` on every registered target before it checks whether the target wants the event. Clipped targets also measure their viewport. All of it runs on the thread that handles keys and renders.

## Fix
- Check `wants(handlers)` first, then measure.
- Measure each target one time per layout commit: cache the boxes and clear the cache from a root layout listener, in line with the single-measurement design of the row Story.
- Run `hit()` one time per move and give the result to both `dragOver` and `hover`.
- Consider `?1002h` (button motion only) when nothing needs hover; keep hover if the controls use it.
- Update `mouse.test.ts`.

## Done when
A pointer move with 100 registered targets measures only targets that handle moves, and measures each one at most one time per commit.
