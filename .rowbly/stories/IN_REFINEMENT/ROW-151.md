ThreadPanel and ThreadPane render the same body inside a different frame.

Files:
- `src/tui/screens/stories/thread-panel/thread-panel.tsx` (lines 91-120)
- `src/tui/screens/threads/thread-pane/thread-pane.tsx` (lines 84-110)

Both render `ThreadDetail`, then a `Box marginTop=1` with a `ConversationView` (`live` when the status is running, active when not steering), then a `ThreadSteerInput` with `key={id}` and the name `${storyId} ${threadName}`.

The pane adds `ThreadChecks`, an Open Story button, wheel focus, full screen and a worker-only steer rule. The panel wraps all in `Panel` and shows the conversation only when `shownId` matches.

Make a `ThreadBody` component for the shared part, with an optional `header` slot and flags for the differences. Each screen keeps its own outer frame.
