## Goal

The attach channel of the host agent sends the new lines of the session file of each remote worker. The main machine then can keep a mirror of the session (ROW-101).

Read the Spec `remote-worker-hosts`, sections "Transport" and "Session mirror".

ROW-92 writes the session files of remote workers on the host. This Story adds `session` frames to `rowbly host attach`: the Thread id, the byte offset of the first line and the complete lines. The main machine can then add each line one time.

Not in scope: the mirror on the main machine and the read of missing lines after a reconnect (ROW-101).
