## Goal
Rerun the profile of the review and compare against the baseline, after all performance Stories are done.

## Baseline (2026-11-16, 125 Stories, 140x38, `agentic-tui` PTY)
| Scenario | Result |
| --- | --- |
| `rowbly --help` | 0.14 s |
| `rowbly story search --json` | 0.22 s |
| `rowbly status --json` | 0.35 s |
| TUI launch to first Story row | 1.5 s |
| CPU busy in a 12 s board session (dev React) | 8.1 s |
| CPU busy in the same session (`NODE_ENV=production`) | 6.6 s |

## Method
- Build with `pnpm build`. Run the TUI with the PTY steps of the `rowbly-screenshots` skill and `--env NODE_OPTIONS="--cpu-prof --cpu-prof-dir=<dir>"`.
- Do the same key sequence: wait for the board, 8 × Down, 2 × Up, Enter, Escape, q.
- Summarize the `.cpuprofile` by inclusive time (React, Ink renderer, Yoga, app functions) and note idle time.
- Record the results in `docs/architecture/tui.md` under a short performance section, with the method.

## Done when
The table has new numbers, the idle board makes no commits between user actions, and any remaining hot spot over 100 ms has a new Story.
