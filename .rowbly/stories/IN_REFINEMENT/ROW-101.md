## Goal

Peek and `inspect_worker` work for remote Threads, also while the host is offline.

Read the Spec `remote-worker-hosts`, section "Session mirror".

## Scope

In scope:

- The main machine keeps a mirror of the session file of each remote Thread in `runtime/sessions/<id>/`.
- New session lines come on the channel. After a reconnect, the main machine gets the missing lines.
- The `conversation/` service and `inspect_worker` read the mirror.
- `rowbly thread log` works for remote Threads.

Not in scope:

- A change to the Pi session format.

## Acceptance criteria

- A line that arrives two times is in the mirror one time.
- Tests cover a mirror after a disconnect and a reconnect.
