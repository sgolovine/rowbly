Four form modals repeat the same save and close code.

Files:
- `src/tui/screens/settings/custom-field-form-modal/custom-field-form-modal.tsx`
- `src/tui/screens/settings/tag-form-modal/tag-form-modal.tsx`
- `src/tui/screens/settings/prompt-form-modal/prompt-form-modal.tsx`
- `src/tui/screens/stages/stage-form-modal/stage-form-modal.tsx`

Each has an `XFormEnv` interface, `useToast`, and a save function that ends with `showToast(info, existing ? "Updated ..." : "Added/Created ...")` and `onSaved(saved)`. Each renders a `FormModal` with the title `existing ? "Edit X › ..." : "New X"`.

The fields, initial values and service call are different and stay in each modal. Make `EntityFormModal<T>({ noun, existing?, titleOf, fields, initialValues, save, labelOf, verb?, onSaved, onClose })` for the rest. Optional: expected saving is about 40 lines.
