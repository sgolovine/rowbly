Split from ROW-99.

## Goal

The user can release a remote Thread. A release abandons the Thread like a cancel (ROW-99), but the Story does not stay `cancelled by user`. The policy can then start a new worker for the Story, for example a local worker, while the old host is offline.

Read the Spec `remote-worker-hosts`, sections "Decisions" (item 10) and "Abandoned Threads".

## Notes

- Rowbly has no release action for a Thread today. This Story adds it: a factory command `release` (for example `rowbly thread release <id>`), and the manager action that uses the abandon steps of ROW-99 with the reason `release`.
- A test examines that a release while the host is offline lets a local worker start for the Story.
- The TUI key is not in scope (ROW-102 or a later Story).
