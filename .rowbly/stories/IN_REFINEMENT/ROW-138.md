## Goal

A TUI user can filter the Story list by tag. Today the TUI has only the Stage filter in the left sidebar. ROW-79 added tags and `rowbly story search --tag`. ROW-80 added tags to the TUI, but a filter by tag was not in its scope.

Original request of the author:

- Whenever a user has tags defined, we split the sidebar on the left hand side into two components.
- The top component should be the stage filter.
- The bottom should be a tag filter.

## Scope

In scope:

- When the Project has one or more tags, the left sidebar has two parts: the Stage filter at the top and a tag filter at the bottom.
- When the Project has no tags, the sidebar is the same as today (only the Stage filter).
- The tag filter limits the Story list to the Stories that have the selected tag. It works together with the Stage filter.

Not in scope:

- A filter by tag in the Story finder.
- Changes to the tag service or the CLI.

## Questions for refinement

- Can the user select one tag or more than one tag? If more than one: must a Story have all of them (AND, the same as `rowbly story search --tag`) or one of them (OR)?
- Does the tag filter have an "All Tags" entry, the same as "All Stages"?
- How does the focus move between the Stage filter and the tag filter (keys and mouse)?
- What happens to the tag filter when the selected tag is removed in Settings?
