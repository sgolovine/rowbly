## Problem
Nothing in `src/` or `tsup.config.ts` sets `NODE_ENV`, so `react/index.js` and `react-reconciler/index.js` load the development bundles in the shipped TUI. A CPU profile of a 12 s board session showed about 1.1 s in dev-only work (`runWithFiberInDEV`, `logComponentRender`, `addObjectDiffToProperties`). With `NODE_ENV=production`, the React render time fell from 3.2 s to 1.0 s.

## Fix
- Set `process.env.NODE_ENV ??= "production"` at the top of `src/cli.ts`, before the dynamic import of `cli-main.js`, or set it with the tsup `env` option. The static imports of `cli.ts` must stay limited to `node:` built-ins and the compile cache.
- Keep the value when the user sets `NODE_ENV` (use `??=`).
- Add a test in `src/cli-startup.test.ts` that the built entry loads the production React bundle.

## Done when
