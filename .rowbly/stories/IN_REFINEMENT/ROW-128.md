## Problem
`src/tui/components/spinner/spinner.tsx:12` starts a `setInterval` of 80 ms for each mounted Spinner. Each tick is a React commit, which lays out the whole tree (see the Story about row measurement). The Spinner is mounted in about 20 places, including toast lines, so the TUI renders up to 30 frames per second while it is idle.

## Fix
- One shared clock (a module-level Store with a subscriber count) that runs only while at least one Spinner is mounted, and that all Spinners read.
- The clock stops when the last Spinner unmounts.
- Consider a slower frame rate (for example 120 ms) if the animation still looks smooth.

## Done when
With two Spinners mounted there is one timer. With none mounted there is no timer. No TUI tests are needed; test the clock store next to it.
