The user should be able to attach items to stories. They should be able to paste things from their clipboard and that should automatically get attached to the story we are on.

The previous version of rowbly had this functionality.

This functionality was part of the "legacy" version of rowbly and should be carried over and implemented in the same way. If you look at the code at this commit: 79a874044292e1fddf3046235a31b8305c10f936, you will see how this feature was implemented.
