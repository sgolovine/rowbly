## Goal

`Tab` and `EditorModeTab` have the same props, the same ref, the same `useMouse` handling and the same ` label ` text. Only the colors are different. Merge the two components into `Tab` with a `variant` prop, so that the TUI has one tab component.

## Scope

In scope:

- Add a `variant?: "accent" | "subtle"` prop to `Tab` (`src/tui/components/tab/tab.tsx`). The default is `"accent"`.
- Use `<Tab variant="subtle" …>` for the `View` and `Edit` tabs in `src/tui/components/full-screen-editor/full-screen-editor.tsx`.
- Delete the folder `src/tui/components/editor-mode-tab/` (`editor-mode-tab.tsx` and `index.ts`).

Not in scope:

- Changes to `Tabs` (`src/tui/components/tabs/tabs.tsx`). It continues to use the default variant.
- Changes to colors in `theme`, or to the layout of the full screen editor.

## Acceptance criteria

- [ ] `Tab` accepts `variant?: "accent" | "subtle"`. With no variant, the output is the same as before (selected: `theme.accent` background, `theme.onAccent` text, bold; not selected: `theme.inkMuted` text).
- [ ] With `variant="subtle"`, the output is the same as the old `EditorModeTab` (selected: `theme.selection` background, bold; not selected: no background and the default text color).
- [ ] `src/tui/components/full-screen-editor/full-screen-editor.tsx` uses `Tab` with `variant="subtle"` for `View` and `Edit`.
- [ ] The folder `src/tui/components/editor-mode-tab/` does not exist, and `grep -rn "EditorModeTab\|editor-mode-tab" src` finds nothing.
- [ ] `pnpm lint`, `pnpm typecheck`, `pnpm test` and `pnpm build` pass.
- [ ] A person sees no change in the full screen editor tabs or the Story modal tabs (manual check, or the `rowbly-screenshots` skill).

## Technical notes

- `src/tui/components/tab/tab.tsx`: Today `Tab` sets `backgroundColor={selected ? theme.accent : undefined}`, `color={selected ? theme.onAccent : theme.inkMuted}`, `bold={selected}`.
- `src/tui/components/editor-mode-tab/editor-mode-tab.tsx`: Today `EditorModeTab` sets `bold={selected}`, `backgroundColor={selected ? theme.selection : undefined}`, and no `color`.
- `EditorModeTab` is used only in `full-screen-editor.tsx` (lines 75–76). It is not exported from `src/tui/components/index.ts`, so no barrel change is necessary.
- Update the JSDoc of `Tab` to describe the two variants.
- Obey the `rowbly-code-style` and `rowbly-tui-design` skills. Use only `theme` colors.
- Do not write tests for the TUI (AGENTS.md rule 4).

## Assumptions

- The `subtle` variant keeps the exact colors of `EditorModeTab`, which includes the default text color (not `theme.inkMuted`) for a tab that is not selected. Reason: the Story is a refactor, and the smallest scope is no visible change.
- The default variant is `"accent"`. Reason: `Tabs` uses `Tab` with no variant, and its look must not change.
