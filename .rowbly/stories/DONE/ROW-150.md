## Goal

The settings rows all use the same column layout: `SelectionRow` > `Box` > some `<Box width={w} flexShrink={0}>` cells > a last cell (usually `<Text wrap="truncate-end">`). Four of them use the same colour rule for a secondary cell (`selected ? theme.inkMuted : theme.inkFaint`). The code is repeated in six places.

Add one shared `ColumnRow` component in `src/tui/components/` and use it in these rows. The result: less repeated code (expected saving: about 120 lines), the same output on the screen, and a smaller "CRUD list section" Story (ROW-146).

## Scope

In scope:

- A new component `ColumnRow` in `src/tui/components/column-row/` (`column-row.tsx` and `index.ts`), exported from `src/tui/components/index.ts`.
- A small exported helper for the shared colour rule, for example `subtleColor(selected: boolean): string` that returns `selected ? theme.inkMuted : theme.inkFaint`, in the same module.
- Use `ColumnRow` in these files:
  - `src/tui/screens/settings/custom-field-row/custom-field-row.tsx`
  - `src/tui/screens/settings/tag-row/tag-row.tsx`
  - `src/tui/screens/settings/prompt-row/prompt-row.tsx`
  - `src/tui/screens/settings/stage-row/stage-row.tsx`
  - the row in the loop of `src/tui/screens/settings/check-list/check-list.tsx`
  - the row in the loop of `src/tui/screens/settings/stage-model-list/stage-model-list.tsx`
- Add a line for `ColumnRow` in the table "The library also contains other code that has no guideline of its own" in `.agents/skills/rowbly-tui-design/SKILL.md`.

Not in scope:

- A `ColumnList<T>` component that also calculates the column widths. The sections continue to call `columnWidth` (`src/tui/screens/settings/column-width.ts`).
- `src/tui/screens/settings/host-list/host-list.tsx` (its row has two lines) and `host-check-items`.
- Rows outside the settings screen (`stories`, `factory`, `threads`).
- The merge of `TagsSection` and `CustomFieldsSection` (ROW-146).
- Changes to the visible output: colours, bold, widths, truncation and click behaviour must stay the same.

## Technical notes

- `SelectionRow` (`src/tui/components/selection-row/selection-row.tsx`) supplies the `▌` bar, the `selection` fill, the scroll focus and the mouse target. `ColumnRow` wraps it: `<SelectionRow selected active onClick><Box>{cells}</Box></SelectionRow>`. Pass `onClick` through unchanged (`CheckList` and `StageModelList` give `undefined` when the rows must not take a click).
- Use a stable `key` for each cell (the column index is acceptable, because the column list is fixed for each row type).
- Keep the text cells in the callers. For example, the last cell of `TagRow` stays `<Text color={subtleColor(selected)} wrap="truncate-end">`. The last cell of `StageRow` is a `Switch`, not a `Text`, so `ColumnRow` must not add a `Text` wrapper.
- Special cases to keep:
  - `PromptRow` has the prop `idle`, which goes to `active`. Its second column has the fixed width `10`. Its first cell uses `selected ? theme.ink : theme.inkMuted` (not the shared rule).
  - `StageModelList.valueColor` returns `theme.ink` when the item is not inherited, else the shared rule.
  - `CheckList` uses no selected colour rule.
- Follow `.agents/skills/rowbly-code-style/SKILL.md` and `.agents/skills/rowbly-tui-design/SKILL.md`. Use only the colours in `theme`. Use `.js` extensions in relative imports.
- Do not write tests for the TUI (AGENTS.md, rule 4). No service changes.

## Assumptions

- Do not add `ColumnList<T>`. Reason: the author marked it as optional, and the smallest scope that gives the saving is `ColumnRow` alone.
- Add a shared helper for the `inkMuted`/`inkFaint` rule. Reason: the author identified the repeated rule, and a helper removes it with a very small change.
- Keep the row components (`TagRow` and the others) as thin wrappers with the same props. Reason: the callers do not change, and ROW-146 can change the sections later.
- Exclude `host-list` and rows outside settings. Reason: the author listed only the six files, and the host row has two lines.
