# Upstream

`SKILL.md` and `LICENSE` are copies of the files in `skills/agentic-tui/` of the
[`@codebolt/agentic-tui`](https://github.com/codeboltai/agentic-tui) package, version 0.3.2. This is
the version that `package.json` pins. Do not change these two files. When you upgrade the package,
copy them again from `node_modules/@codebolt/agentic-tui/`.

The CLI is a devDependency. Run it as `pnpm exec agentic-tui`, not as `agentic-tui` alone. For
screenshots of Rowbly, follow `../rowbly-screenshots/SKILL.md`. That skill adds the steps that are
specific to Rowbly.
