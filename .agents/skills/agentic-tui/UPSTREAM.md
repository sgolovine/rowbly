# Upstream

`SKILL.md` and `LICENSE` are copied unchanged from `skills/agentic-tui/` in the
[`@codebolt/agentic-tui`](https://github.com/codeboltai/agentic-tui) package, version 0.3.2, the
version pinned in `package.json`. When you upgrade the package, copy them again from
`node_modules/@codebolt/agentic-tui/`.

The CLI is installed as a devDependency: run it as `pnpm exec agentic-tui`, not as a bare
`agentic-tui`. For screenshots of Rowbly, follow `../rowbly-screenshots/SKILL.md`, which adds the
Rowbly-specific steps to this skill.
