## How to execute this report

Severity: **major** means an unsafe API contract or substantial observable defect; **minor** means a local behavior, clarity, or maintainability issue; **nit** means a small readability or consistency improvement. The earlier report substantially overused “major” for ordinary duplication and naming preferences.

Disposition: **P** = recommended before release; **U** = useful improvement; **O** = optional cleanup or abstraction, safe to defer; **W** = withdrawn, do not implement; **M** = merged into another ID, do not create a second task. P does not automatically mean a release blocker. **C** means confirmed by current source; **C/I** means the code pattern is confirmed but the stated downstream impact or desired policy is inferred. No runtime reproduction was executed in this continuation. Acceptance cases below are proposed checks for implementers, not claims that they already pass.

For comments, renames, deletion of redundant annotations, and equivalent local simplifications, acceptance means the specified source change plus the supervisor's typecheck/lint and existing relevant tests. Do not add tests that merely repeat the implementation. Add behavioral tests only where listed. All paths and line numbers refer to the revision above; locate by the quoted symbol after another task moves files.
