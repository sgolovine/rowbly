# Tasks

A Built-in Plugin that splits a Story into Tasks, each with its own Stage.

## Language

**Task**:
A smaller unit of work inside exactly one Story, with its own name, description and Stage; it has no Assignees of its own and belongs to the Story's Assignees.
_Avoid_: sub-task, subtask, checklist item

**Task Id**:
The permanent identifier of a Task: its Story's Story Key, a dot and a number that is never reused in that Story (for example `WEB-42.3`).
_Avoid_: task key
